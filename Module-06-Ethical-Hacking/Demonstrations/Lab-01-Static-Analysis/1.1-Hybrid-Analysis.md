# Lab 1.1 — Static Analysis Using Hybrid Analysis

## 🎯 Objective

Perform basic static and automated analysis of a Windows executable using Hybrid Analysis.

For this demonstration, the Windows `notepad.exe` executable is used as a benign sample to understand the malware-analysis workflow and how automated analysis platforms present file information and behavioral indicators.

> ⚠️ **Safety:** Only upload files to external analysis platforms when you are authorized to do so and the file does not contain sensitive or confidential information.

---

## 🧪 Requirements

- Windows analysis VM
- `notepad.exe`
- Internet access for the analysis platform
- Web browser
- Hybrid Analysis

---

## 🖥️ Sample Information

Sample used:

```text
notepad.exe
```

Location on Windows:

```text
C:\Windows\System32\notepad.exe
```

Verify that the file exists:

```powershell
Test-Path C:\Windows\System32\notepad.exe
```

Expected result:

```text
True
```

---

## Step 1 — Open Hybrid Analysis

- Open the Hybrid Analysis website in a web browser.
- Navigate to the file-analysis submission interface.

---

## Step 2 — Submit the Sample

- Select the option to upload a file.
- Choose:

```text
C:\Windows\System32\notepad.exe
```

- Follow the platform's submission instructions.
- Do not upload confidential, proprietary, or personal files to a public malware-analysis service.

---

## Step 3 — Review the Analysis Result

After the analysis is complete, examine the report.

Look for information such as:

- File name
- File type
- File size
- SHA-256
- MD5
- File classification
- Threat score/verdict
- MITRE ATT&CK techniques, if reported
- Extracted strings
- Network indicators
- Process information
- File activity
- Registry activity

## Step 5 — Examine Behavioral Information

If behavioral information is available, inspect sections such as:

- Processes
- Files
- Registry
- Network
- DNS

Because `notepad.exe` is a benign Windows executable, the observations should be interpreted in the context of normal Windows application behavior.

Do not assume that the presence of an API, registry operation, or network-related field automatically indicates malicious activity.

---

## Step 6 — Examine MITRE ATT&CK Information

If Hybrid Analysis provides MITRE ATT&CK mappings, inspect them.

Record any techniques reported by the platform.

For a benign sample, the absence of malicious ATT&CK techniques is also a valid observation.

---

## Step 7 — Examine Extracted Strings

Review any strings identified by the platform.

Look for:

- File paths
- DLL names
- API names
- URLs
- Domain names
- IP addresses
- Registry paths
- Error messages

Compare these observations with the results obtained later using BinText.

The workflow demonstrated in this lab is:

```text

     ↓
Calculate Hash

```
