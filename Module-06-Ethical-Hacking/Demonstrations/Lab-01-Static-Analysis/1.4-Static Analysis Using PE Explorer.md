Lab 1.4 — Static Analysis Using PE Explorer
🎯 Objective

Use PE Explorer to inspect the internal structure of a Windows Portable Executable (PE) file during static malware analysis.

For this demonstration, the benign Windows executable notepad.exe is used as the analysis sample.

🧪 Requirements
Windows analysis VM
notepad.exe
PE Explorer
Isolated malware-analysis environment
⚠️ Safety

This demonstration uses the legitimate Windows notepad.exe executable.

When analyzing actual malware, always use an isolated virtual machine and take a clean snapshot before beginning the analysis.

🖥️ Sample Used
notepad.exe

Default location:

C:\Windows\System32\notepad.exe

Verify the file exists:

Test-Path C:\Windows\System32\notepad.exe

Expected result:

True
Step 1 — Launch PE Explorer

Open PE Explorer on the Windows analysis VM.

PE Explorer allows analysts to inspect different components of Windows PE files.

Step 2 — Load the Sample

Open:

C:\Windows\System32\notepad.exe

PE Explorer will parse the executable and display information about its PE structure.

Step 3 — Examine the DOS Header

Locate the DOS Header information.

The DOS header is the first part of a Windows PE executable.

Look for fields such as:

e_magic
e_lfanew

The e_magic field normally contains:

MZ

Record the information displayed by PE Explorer.

Step 4 — Examine the PE Header

Navigate to the PE Header / NT Headers section.

Examine information such as:

Machine
Number of Sections
Time/Date Stamp
Size of Optional Header
Characteristics

Record the values shown by your version of PE Explorer.

Example:

Machine: <observed value>
Number of Sections: <observed value>
Time/Date Stamp: <observed value>
Characteristics: <observed value>
Step 5 — Examine the Optional Header

Inspect the Optional Header.

Look for fields such as:

Image Base
Entry Point
Section Alignment
File Alignment
Image Size
Subsystem

The Entry Point identifies the location where execution begins.

Record:

Entry Point: <observed value>
Image Base: <observed value>
Subsystem: <observed value>
Step 6 — Examine Sections

Open the Section Headers or Sections view.

You may see sections such as:

.text
.rdata
.data
.pdata
.reloc

Examine properties such as:

Section Name
Virtual Size
Raw Size
Virtual Address
Characteristics

Record the sections actually displayed:

Section	Virtual Size	Raw Size	Characteristics
<observed>	<value>	<value>	<value>
<observed>	<value>	<value>	<value>
Step 7 — Examine Imports

Open the Import Directory / Imports section.

Imports show external libraries and functions that the executable references.

Look for:

DLL names
Imported functions
Windows API functions

Examples of DLL categories you may encounter include:

KERNEL32
USER32
ADVAPI32
SHELL32

Record only the DLLs and functions actually displayed for your notepad.exe.

Step 8 — Examine Exports

If an Exports section is present, inspect it.

Exports represent functions or symbols made available by the executable to other programs.

Record:

Exports: <observed information>

If PE Explorer shows no exports, record:

Exports: None observed
Step 9 — Examine Resources

Open the Resources section.

Resources can contain items such as:

Icons
Dialogs
Menus
Version information
Manifest
Embedded data

Inspect the available resource entries.

Record interesting observations:

Resources:
<observed resource types>

🔍 Understanding the Results

PE Explorer allows you to move from a basic executable overview to a more detailed PE-structure analysis:

notepad.exe
     ↓
DOS Header
     ↓
PE Header
     ↓
Optional Header
     ↓
Sections
     ↓
Imports / Exports
     ↓
Resources

This information helps establish what components are present inside the executable.
